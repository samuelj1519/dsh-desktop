# 客户端实现

[English](client.md) | [简体中文](client.zh-CN.md)

## 后端状态与限制

`BackendManager` 和 `src/contracts.ts` 是传输状态的权威来源。设置页读取不可变投影，另外显示页面错误、进行中的参数检查和未完成的退出。不创建会话状态或模型成功状态。

`src/config.ts` 在受信边界解析自有启动的限制：

| 限制 | 默认值 |
| --- | --- |
| 启动期限 | 45 秒 |
| HTTP 健康检查期限 | 3 秒 |
| 正常停止宽限期 | 7 秒 |
| 强制退出等待 | 2 秒 |
| 保留的后端诊断 | 64 KiB |
| Node `--version` 检查 | 3 秒，输出 4 KiB |

路径必须为绝对路径。所选 Node 程序必须可执行，dsh CLI 必须可读。路径发现读取 PATH、常见安装目录和 realpath，不调用 dsh `--help`。

## 窗口与 IPC

`src/main.ts` 创建两类窗口：

- **本地设置页**：加载 `ui/index.html`，通过沙箱 CommonJS preload 暴露 `config`、`state`、`connect`、`stop`、`choose` 和状态订阅。每个 IPC handler 校验发送方的 webContents、主 frame 和精确本地文件 URL。字段、类型或长度不符时拒绝请求。未知配置字段会报错，不会被静默丢弃。
- **dsh 服务页**：直接加载已验证的本机回环 URL，不加载 preload，也没有 Node 桥。两类窗口均启用沙箱和上下文隔离，并禁用 Node 集成。

设置页拒绝浏览器权限和网络请求。服务页的浏览器权限仅允许同源安全剪贴板写入，保留标准复制、剪切和粘贴菜单。dsh 工具授权仍由服务的同源 UI 负责。

服务窗口的导航和重定向必须留在当前 HTTP 回环源内。阻止新窗口、外部源、文件跳转和 webview。设置页仅允许自身文件 URL。同源 fetch 和 WebSocket 直接与 dsh 通信；客户端不复制 RPC 实现。页面渲染失败时保留连接事实，并单独显示错误。

## 持久化与修复

成功连接的参数以版本 1 的 `connection.json` 保存在应用 `userData` 中。`DSH_DESKTOP_USER_DATA` 在 Electron 就绪前同时设置 `userData` 和 `sessionData`，必须使用绝对路径。

损坏设置不触发自动恢复。只有显式修复且连接成功后才保存，同时保留带时间戳的损坏原件副本。退出时保留自有 Home、工作目录和 dsh 持久服务记录。不将模型凭据复制到客户端设置。

## 退出协调

退出及关闭最后一个可见窗口时，等待 `dispose()` 完成。开始退出后，进行中的参数检查失去启动资格。只有后端清理成功且参数检查结束后，客户端才调用退出。

清理失败时保留错误和所有权，并显示设置页供重试退出。不报告为空闲，也不另启后端绕过清理。进程组语义和验证要求见[架构设计](design.zh-CN.md)。
